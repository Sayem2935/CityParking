AUTHENTICATION (AuthController)
================================================================================

POST /api/auth/register
  Description: Register a new user account
  Auth Required: No
  Request Body:
    - firstName: string (required)
    - lastName: string (required)
    - email: string (required)
    - password: string (required)
    - universityId: string (optional)
  Response: 201 Created
    - token: JWT token
    - user: User object

POST /api/auth/login
  Description: Authenticate an existing user
  Auth Required: No
  Request Body:
    - email: string (required)
    - password: string (required)
  Response: 200 OK
    - token: JWT token
    - user: User object

VEHICLES (VehicleController)
================================================================================

GET /api/vehicles
  Description: Get all vehicles for authenticated user
  Auth Required: Yes (JWT)
  Response: 200 OK
    - Array of vehicle objects

GET /api/vehicles/{id}
  Description: Get vehicle by ID
  Auth Required: Yes (JWT)
  Path Params: id (Long)
  Response: 200 OK
    - Vehicle object

POST /api/vehicles
  Description: Create a new vehicle
  Auth Required: Yes (JWT)
  Request Body:
    - plateNumber: string (required)
    - vehicleType: string (required) [CAR, MOTORCYCLE]
    - make: string (optional)
    - model: string (optional)
    - color: string (optional)
  Response: 201 Created
    - Created vehicle object

PUT /api/vehicles/{id}
  Description: Update an existing vehicle
  Auth Required: Yes (JWT)
  Path Params: id (Long)
  Request Body:
    - plateNumber: string (optional)
    - vehicleType: string (optional) [CAR, MOTORCYCLE]
    - make: string (optional)
    - model: string (optional)
    - color: string (optional)
  Response: 200 OK
    - Updated vehicle object

DELETE /api/vehicles/{id}
  Description: Delete a vehicle
  Auth Required: Yes (JWT)
  Path Params: id (Long)
  Response: 200 OK

PARKING (ParkingController)
================================================================================

GET /api/parking/availability
  Description: Get parking availability
  Auth Required: No
  Query Params:
    - zone: string (optional) [AB4, ENGINEERING]
  Response: 200 OK
    - Array of availability objects (zone, totalSlots, availableSlots, occupiedSlots)

POST /api/parking/assign
  Description: Assign parking slot to vehicle
  Auth Required: Yes (JWT)
  Request Body:
    - vehicleId: Long (required)
    - zone: string (required)
  Response: 200 OK
    - assignmentId, slotNumber, zone, vehiclePlate, assignedAt

POST /api/parking/release
  Description: Release parking slot
  Auth Required: Yes (JWT)
  Request Body:
    - assignmentId: Long (required)
  Response: 200 OK

GET /api/parking/statistics
  Description: Get parking statistics
  Auth Required: Yes (JWT)
  Query Params:
    - zone: string (optional) [AB4, ENGINEERING]
  Response: 200 OK
    - zone, totalSlots, availableSlots, occupiedSlots, utilizationRate, todayEntries, todayExits

================================================================================
ERROR RESPONSES
================================================================================

400 Bad Request: Validation error
401 Unauthorized: Authentication required
403 Forbidden: Access denied
404 Not Found: Resource not found
409 Conflict: Resource already exists
422 Unprocessable Entity: Business logic error
500 Internal Server Error: Server error

All responses follow the ApiResponse format:
{
  "success": boolean,
  "message": string,
  "data": object | null
}
